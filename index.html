Frequently Asked Questions

What is a YouTube transcript?

A YouTube transcript is the text version of the spoken words in a video, generated automatically or uploaded by the creator.

Can every YouTube video be transcribed?

Videos must have captions available or support AI fallback transcription through our backend API service.

Is my API key secure?

Yes! The API key is stored securely on the server environment variables (`SUPADATA_API_KEY`) and is never exposed in client-side code.

Can I download my transcript?

Yes! You can instantly download your transcript as a .txt file using the download button or copy it directly to your clipboard.
